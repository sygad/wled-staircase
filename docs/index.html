WLED Staircase — interactive demo

The Home Assistant card on the left, the stairs on the right. Everything here runs the same logic as the real thing: 64 steps, 100 ms per step, a 5 second hold that starts after the sweep finishes. The project is on GitHub.

Conditions

The stairs are live only when Power is on and it's Night (or Moon is on). With the alarm armed home, the top sensor goes to Danger instead of a sweep.
